# Character figures (Grok)

The figures that stand on the hex field. Painted in the same style and camera angle as the props. Only right-facing poses are needed: the game mirrors them for left.

After generating: put the sheet in `extras/`, add it to `SHEETS` in `tools/cut_sheets.py` (names: heroine-stand, heroine-walk, sylvie-stand, sylvie-walk), and run the cutter.

The background is one solid, flat, pure magenta colour (#FF00FF), continuous behind every figure across the whole image. Do not draw a card, panel, frame or box behind any figure.
